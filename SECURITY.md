# Security Policy

## Supported Versions
Security updates and patches are actively maintained for the latest release branch of this project.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We take the security of this project seriously. If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, please report it privately using one of the following methods:
1. **GitHub Private Vulnerability Reporting:** Navigate to the **Security** tab of this repository and click **"Report a vulnerability"**.
2. **Direct Contact:** Reach out directly to the lead maintainer via the contact details listed on the maintainer's GitHub profile (`@kazubuike114-art`).

### What to Include
To help us triage and resolve the issue quickly, please include:
* A clear description of the vulnerability and potential impact.
* Step-by-step instructions or a proof-of-concept script to reproduce the issue.
* Affected components, endpoints, or configuration details.

### Disclosure Timeline
* **Initial Response:** Within 48 hours of submission.
* **Triage & Assessment:** Within 5 business days.
* **Fix & Public Advisory:** Once a patch is verified, we will coordinate a GitHub Security Advisory (GHSA) and credit the reporter (unless anonymity is requested).
